Meu primeiro projeto “híbrido”, com duas camadas distintas:
Camada de usuário (frontend): desenvolvida em PHP e JavaScript, é responsável por renderizar as páginas, validar dados e realizar requisições antes do envio ao backend.
Camada de backend: implementada em Java com Spring Boot + JWT e conectada ao PostgreSQL, concentra toda a lógica de negócios, processamento de dados e validações de segurança.
